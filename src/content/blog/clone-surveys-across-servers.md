You can now clone surveys across servers! 🎉

See a survey in another server that you'd like to use? Right-click it → Apps → Clone and Subo will copy it straight into your server: clean slate, ready to customize.

**What carries over:** questions, scoring, logic, and answers.

**What gets reset:** channels, roles, XP settings (you configure those for your own server).

The project (poll or survey) lands in your server as inactive. Just set it up and go live when you're ready.

Cloning is also how you run the same survey twice on purpose. A [pre and post assessment](/recipes/pre-post-assessment/) is one project cloned with the dates changed, which is what keeps the two waves comparable: identical questions, identical score buckets, a before and after you can join per member.

To share your own projects, enable "Allow others to clone this project" in the project's Details tab and/or in your server Settings for new projects.

Want inspiration? Everything posted here in the [Support server](/support/) is fair game to clone, and the [template library](/templates/) is already built to be cloned. Try one!
