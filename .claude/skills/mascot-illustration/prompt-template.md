# Prompt Skeleton

Fill this in and each new illustration becomes a short job instead of a blank
page. Keep the character, style, and negatives constant; only the top half
changes per feature.

```
SCENE
  <the metaphor's environment, one line (see recurring-metaphors.md)>

MAIN ACTION
  <what Subo is actively doing: presenting / pressing / painting / handing over>

SUPPORTING CHARACTER
  <the Discord blob and its reaction: wonder / discovery / "aha">

BACKGROUND
  <2 to 3 readable elements only; slightly blurred; breathing room>

PROPS
  <the feature demonstration + optional "old way kicked aside" gag>

LIGHTING
  Warm cinematic, soft key + rim, pink/cyan accents, slight bloom, shallow DoF

PALETTE
  Warm metallics + teal accents + pink highlights.
  <category hue if relevant>. Purple only where intended.

COMPOSITION
  2:1 ratio. Eye level, slight wide angle. Subo dominant, blob second,
  feature third, background last.

STYLE
  Pixar / WALL-E / modern high-end 3D animation.

NEGATIVE
  No photorealism, painterly, anime, or flat illustration.
  No invented text or names. No malformed hands/eyes. No missing mouth.
  No merged limbs. No clutter.
```

## Reminders while filling it in
- Read [subo-character-sheet.md](subo-character-sheet.md) first; the model does
  not know Subo's canon, so restate the key traits (bar-chart head, square-in-
  square left eye, checkbox right eye, lime body, pink outline) in the prompt.
- **One metaphor only.**
- Image size and format may be edited in Photopea afterward
  ([photopea-workflow.md](photopea-workflow.md)).
- Run the review checklist in [SKILL.md](SKILL.md) before shipping.
