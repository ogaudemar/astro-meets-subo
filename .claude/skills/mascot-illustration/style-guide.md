# Art Direction & Style Guide

The look that stays constant across every scene. Costume and setting change; this
does not.

## Rendering
- **Always:** Pixar / WALL-E / modern Disney / high-end 3D animation.
- **Never:** photorealistic, painterly, anime, or flat illustration.

## Lighting
- Warm, cinematic.
- Soft key light + rim lighting.
- Pink / cyan accent lights.
- Slight bloom, shallow depth of field.

## Materials
- Glossy plastic, soft rubber.
- Rounded edges, no sharp corners.
- Pink emissive borders.

## Palette
- Base: warm metallics (metallic gray), **teal** accents, **pink** highlights.
- **Purple is a special-purpose color**, not a default. Reserve it for a specific
  intent (e.g. a destination planet, a recolored clone). Keep interiors low on
  purple.
- **Category hues:** each product category gets its own dedicated hue so color
  itself carries meaning. The template shelves (CONNECT / DISCOVER / ORGANIZE)
  are the clearest example.

## Composition
### Focal hierarchy (strict order)
1. Subo
2. Supporting character (the blob)
3. The feature demonstration
4. Everything else is background

### Background
- Exists to support, never to compete.
- Often slightly blurred.
- Large empty breathing areas.
- Only **2 to 3** readable background elements.

### Camera
- Eye level.
- Slight wide angle.
- Cinematic.
- No bird's-eye / top-down.

## UI language (how product surfaces are drawn)
### Discord embeds
Rounded, glowing, large, readable. Not floating randomly unless intentional.

### Shelf / section labels
Large, simple wording (CONNECT, DISCOVER, ORGANIZE). Distinct hues. Only a few
cards each.

### Signs & baked-in text
Large, simple wording. Avoid paragraphs. The generation model now renders
specified text reliably, so **write intentional, story-serving copy directly
into the brief** (sign wording, a statement's line items, a poll question) rather
than planning to add it later. Only include text that serves the story; keep it
sparse so the image stays uncluttered. Photopea is for size and export, not text
fixes.

## Format
- **2:1 fixed ratio** by default.
- Simple and uncluttered beats detailed and busy, every time.
